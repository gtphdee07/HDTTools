# Streamlit stays on Tesseract OCR forever; Claude vision is Web/Android-only

Streamlit is a free, public-service demo (Streamlit Community Cloud), not a lower tier of the paid product — it was never meant to gain accounts, credits, or Claude-vision scanning. Decided permanently 2026-09-21: switching Streamlit to Claude vision would expose an unbounded-cost API call on a live, public, unauthenticated surface with no cost-gating mechanism (unlike Web/Android, which sit behind Scan Proxy's credit system). Web independently moved to Claude-vision-only (see `ClaudePlans/2026-09-21-drop-tesseract-web-api-only.md`); Streamlit's `HDTTOOLS_OCR_BACKEND` env var keeps defaulting to `"tesseract"`, with `"claude"` only as a manual, opt-in dev-time comparison — never a real Streamlit deployment configuration.
